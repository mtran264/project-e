        Back up your data

        A backup is one JSON file with all inventory, sales, returns, expenses, preorders, marketplaces, and goals.

        Restore from backup

        Choose a JSON backup file exported from this app.

        Merge keeps your current records and adds records from the backup. It can create duplicates if the same backup is restored more than once.

        Clear all data

        This deletes all inventory, sales, returns, expenses, and preorders on this device, and resets marketplaces and goals. It can't be undone. Export a backup first.

        Privacy

        Your data stays on this device. Nothing you enter is saved to or synced with an online server.

        Inventory, sales, returns, expenses, and preorders are saved in this browser's IndexedDB. Export a backup file to keep a copy or move data to another device. Clearing browser data erases anything you haven't exported.
